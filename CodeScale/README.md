# CodeScale 码尺

CodeScale 是一个面向企业 AI 项目的价值验收台。它不只记录“是否使用 AI”，而是把每项业务任务的改造前基线、实际投入、验收结果和证据状态放到同一套口径中，帮助团队判断 AI 是否真正降低成本、提高合格率并减少人工工作。

在线版本：[codescale-ai-mvp.yangzizhu2024.chatgpt.site](https://codescale-ai-mvp.yangzizhu2024.chatgpt.site)

> 当前站点为私有站点，仅已授权用户可以访问。

## 核心功能

### 1. 项目总览

- 展示当前总投入、合格成果全成本、相对基线的成本变化和累计节省工时。
- 用柱状图对比各项任务改造前后的单个合格成果成本。
- 展示 AI、人工、返工、集成摊销和运维五类成本构成。
- 汇总任务状态，快速识别已改善、待复核和未达基线的任务。

### 2. 任务台账

每条任务记录包含三类信息：

- 任务与验收：任务名称、部门、日期、验收规则、验收负责人和证据状态。
- 改造前基线：基线总成本、基线合格成果数和基线平均耗时。
- 改造后数据：AI 费用、人工成本、返工成本、集成摊销、运维成本、任务量、合格成果数、人工接管数和平均耗时。

台账支持关键词搜索、状态筛选、删除记录和 CSV 导出。

### 3. 效能诊断

系统根据已登记的数据自动计算：

- 基线对比得分。
- 未达基线的任务数量。
- 已验证的成本变化。
- 返工比例、人工接管率和证据完整度。

诊断建议只使用台账中的真实数据，不自动虚构收益。例如，系统可能建议缩小任务范围、复盘返工样本、补充验收证据或设置分级人工接管。

### 4. 价值报告

- 自动生成报告周期和管理摘要。
- 汇总总投入、成本变化、成果成本变化和成功率变化。
- 按任务展示改造前后对比和建议动作。
- 支持通过浏览器打印功能保存为 PDF。

### 5. 数据可信度

侧边栏的数据质量分数综合考虑关键字段完整度和证据状态。证据状态分为：

- `证据完整`：已有可追溯的验收或抽样记录。
- `部分证据`：已有部分记录，但不足以完整复核结论。
- `仅业务口径`：目前主要是业务方描述，尚未补齐原始证据。

## 快速使用

### 在线使用

1. 打开在线站点并完成授权登录。
2. 点击右上角的“记录任务”。
3. 填写任务信息和验收口径。
4. 填写同一任务量口径下的改造前基线。
5. 填写改造后的各项实际成本和结果。
6. 点击“保存并诊断”。
7. 在“效能诊断”中查看问题，在“价值报告”中生成汇报材料。

### 本地使用

本项目是无需构建步骤的静态网页，可以直接打开 `dist/index.html`，也可以启动一个本地静态服务器：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173`。

## 指标口径

### 当前总投入

```text
当前总投入 = AI 费用 + 人工成本 + 返工成本 + 集成摊销 + 运维成本
```

### 合格成果全成本

```text
当前合格成果全成本 = 当前总投入 / 当前合格成果数
基线合格成果全成本 = 基线总成本 / 基线合格成果数
```

### 成功率

本版本按同一任务总量比较改造前后的合格率：

```text
当前成功率 = 当前合格成果数 / 任务总数
基线成功率 = 基线合格成果数 / 任务总数
```

因此，录入基线时应保证基线合格成果数与当前数据采用相同的任务量和验收标准。

### 任务状态

- 已验证改善：成果成本至少下降约 12%，且成功率不低于基线。
- 待复核：成果成本没有明显恶化，且成功率与基线基本接近。
- 未达基线：成本或成功率未达到上述条件，需要进一步复盘。

状态用于提示优先级，不替代财务审计或业务验收结论。

## 推荐录入流程

为了让对比结果可信，建议按以下顺序使用：

1. 先定义业务任务边界，避免把不同复杂度的任务混在一起。
2. 固定合格成果的验收规则，并指定验收负责人。
3. 收集同一任务量、同一时间范围的改造前基线。
4. 完整记录 AI、人工、返工、集成和运维成本。
5. 保存抽样结果、验收记录或原始数据链接作为证据。
6. 先小范围验证，再根据诊断结果决定是否扩大使用。

## 数据存储说明

当前 MVP 使用浏览器 `localStorage` 保存任务数据：

- 数据仅保存在当前浏览器和当前站点域名下。
- 更换浏览器、设备或清理站点数据后，记录不会自动同步。
- 删除任务会立即修改本地数据。
- 建议定期使用“导出 CSV”备份台账。

演示数据在首次打开时自动加载。后续录入会保存在 `codescale.tasks.v2` 这个本地存储键中。

## 当前限制

- 尚无账号体系、团队协作和跨设备数据同步。
- 尚未连接企业财务、工单、CRM 或模型调用账单。
- 基线任务量与当前任务量默认采用同一口径。
- 报告结论依赖录入数据和证据质量，不应直接视为审计结果。
- 当前适合作为价值验证 MVP；正式生产使用前应接入数据库、权限控制、操作日志和备份机制。
